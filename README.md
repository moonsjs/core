# @moonsjs/core

Router file-based, typegen, config, error §15, serialisasi devalue, dan runner
loader/middleware untuk framework [**Moons**](https://github.com/moonsjs/docs)
— full-stack TypeScript yang membuat kebocoran kode server ke client mustahil.

- Dokumentasi API: [docs/api/core.md](https://github.com/moonsjs/docs/blob/main/docs/api/core.md)
- Subpath: `@moonsjs/core/serialize` (encode/decode payload, browser-safe)
